TECHNICAL EVENT

AI PROMPT WAR

GENERAL RULES & INSTRUCTIONS (Individual participant only)

  1. Participants must create one complete and functional website using AI.
  2. Each participant is allowed a maximum of 5 AI prompt attempts throughout the competition.
  3. The website should be clean, attractive, responsive, and user-friendly.
  4. All required features must work properly, and the completed website must be submitted within the given time limit.
  5. Participants must create their prompts during the competition. Pre-written or copied prompts are not permitted.
ROUND 1PROMPT STARTER5 minutes
  1. A simple website problem statement will be provided.
  2. Participants must create their own prompt.
  3. The AI will generate the website based on the prompt.
  4. Only basic functionality is expected.
ROUND 2ROLE PROMPT CHALLENGE8 minutes
  1. A moderate website requirement will be provided.
  2. Participants must assign a suitable role to the AI.
  3. The website should contain multiple functional features.
ROUND 3COMPLEX SCENARIO10 minutes
  1. A complex scenario with multiple requirements will be given.
  2. Participants must communicate several conditions clearly.
  3. The generated website must contain working functionality.
  4. Judges will test the important features.
ROUND 4FINAL PROMPT WAR17 minutes
  1. A surprise problem statement will be announced.
  2. Participants must understand the problem quickly.
  3. Only their remaining AI prompt attempts can be used.
  4. The final website must be functional.
  5. Judges will conduct a live demonstration and functionality test.

Read all rules carefully before entering the competition.
